Activity: Explanation of Each Tag

<b> is used to make text bold.

<strong> is used to indicate important text.

<i> is used to display text in italic style.

<em> is used to emphasize text.

<u> is used to underline text.

<mark> is used to highlight text.

<small> is used to display smaller text.

<del> is used to show deleted text.

<ins> is used to show inserted text.

<sub> is used to display subscript text.

<sup> is used to display superscript text.
